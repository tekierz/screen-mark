Review findings resolved

FindingCorrection and retained lesson
Generated table ambiguityMarker ownership is bounded by a recognizable local table; a distant sentinel never expands a replacement range. A generated-looking Total section name cannot truncate the true generated block.
Numeric round-trip precisionCheck cent safety in both directions through the public dollar interface; safe integer cents alone do not guarantee an exact numeric-dollar round trip at large magnitudes.
Scene plus page-sized dialogueWhen a scene heading and an otherwise page-sized dialogue cannot fit together, scene continuity takes precedence and the dialogue splits with continuation markers. Whole-dialogue movement applies when the complete keep group fits.
Parenthetical-only split boundariesRetain dialogue-part semantics while paginating so a parenthetical is not mistaken for retained speech.
Fountain lexer precedenceTest serialized text through an independent importer. Natural-looking transitions, bare scene prefixes and multiline note delimiters require explicit handling to preserve the parsed type and visible text.
Incomplete dependency noticesBundled distributions without license files use exact-version, metadata-hash-checked supplements with upstream provenance. Brotli decoder Google/Apache notices and the SWC repository notice are included separately from package-level MIT declarations. Unknown or changed omissions fail the build.

Verified limits

  • PDF uses existing Courier/WinAnsi coverage. Unsupported glyphs and impossible title/cue layouts produce errors; fonts are not shrunk or silently substituted.
  • Fountain syntax that cannot preserve literal text is rejected. The pinned development-only importer, fountain-js 1.2.4, crashes when a dialogue starts with a lyric. That narrow valid export remains unverified by this importer; standalone lyrics and lyrics after speech are semantically verified.
  • Scene eighths are conservative scheduling estimates, not physical page count: max(1, ceil(occupiedRows × 8 / 54)), summed per scene. Title/pre-scene rows, control markers and unused page tails are excluded. Silent performers are not inferred.
  • Real-host evidence covers local macOS VS Code 1.101.1. The harness uses the installed extension directory as its development target to enable the external test runner; all extension runtime code and assets still load from the installed VSIX.
  • Separate audit observations about outline nesting, comment highlighting and comment-only dialogue policy remain outside this approved remediation scope.
